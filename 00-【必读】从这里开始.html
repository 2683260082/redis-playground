1这是什么？

一个带网页界面的 Redis 实验室：每按一个按钮，页面顶部就会回显这次操作对应的真实 Redis 命令和返回值。

怎么学：每个页面顶部有「概念」讲解块（类型用途 + 直觉类比）， 中间是可视化操作区，每次操作的命令回显在页面顶部—— 把「界面动作」和「命令行」一一对应起来，就是最直观的 Redis 入门。

2Redis 核心概念速查

Redis = 把数据放在内存里的键值数据库，读写微秒级。六大结构一张表：

类型直觉类比关键命令典型场景
string 一张便利贴 / 一个计数器 SET GET INCR EXPIRE 缓存 JSON、页面 PV 计数、验证码
list 两端能进出的传送带 LPUSH RPOP LRANGE 消息队列、任务排队、最新 N 条
hash 一个档案袋（字段-值） HSET HGETALL HDEL 用户资料、对象的部分字段更新
set 不重复的名单（无序） SADD SMEMBERS SINTER 标签、去重、共同好友（交集）
zset 带分数的排行榜 ZADD ZRANGE ZREM 排行榜、延时队列、范围推荐
过期 TTL 定时销毁的便签 EXPIRE TTL PERSIST 缓存自动失效、限流窗口
两个必须懂的数字：在 STRING 页看 TTL 倒计时归零键自动消失； 在 SET 页重复 SADD 同一元素返回 0（没新增）—— 这两个细节是面试和实战的高频点。

3怎么运行？（三步）

双击 01-【双击开始】.bat 自动检查 Python 和依赖，缺什么装什么，并探测本机 Redis 服务。
浏览器自动打开 http://127.0.0.1:5000 顶部徽章显示当前模式：绿色「真实模式」= 连上了 Redis 服务；琥珀色「模拟模式」= 使用内存模拟器。
按第 4 节的学习路线逐页玩 每页先读「概念」块，再动手；观察页面顶部的命令回显。
双模式说明：没装 Redis 也能完整学习——自动降级为 fakeredis 内存模拟器，命令与 API 和真实 Redis 完全一致。 想要真实模式，任选：winget install Memurai.MemuraiDeveloper （Windows 服务，本项目开发即用它），或 docker run -d -p 6379:6379 redis:7。 装好重启本项目即可。

4推荐学习路线

按顺序玩一遍（约 30 分钟），Redis 的骨架就建立起来了。

0
先打开网站顶部「GUIDE 新手上路」4 个红按钮跟着点，60 秒建立「储物柜墙」心智模型——这一步最重要。
1
总览页认识全局看顶部状态卡片（版本/内存/键数），用键浏览器点开任意键。
2
STRING：写入 + TTL 倒计时SET 一个键并设 TTL 60，盯着大数字倒计时到 0，键自动消失。
3
STRING：INCR 计数器连点 INCR 观察原子自增——这就是网站 PV 的实现方式。
4
LIST：体验 FIFORPUSH 推入几个任务，LPOP 从另一头弹出——先进先出。
5
HASH：更新对象字段给 demo:user 写 name/age/email，理解「只改一个字段」的含义。
6
SET：去重 + 交集重复 SADD 看返回 0；建两个集合并 SINTER 求共同标签。
7
ZSET：一键生成排行榜点「写入演示数据」看分数排序；给第一名改低分观察实时重排。
8
CACHE：缓存的价值连点两次「带缓存」（第二次毫秒级 HIT），再「绕过」看 800ms——对比即理解。
9
回总览 FLUSHDB 收尾清空所有键，键浏览器归零，复习一遍 SCAN 和 DBSIZE。

7常见问题

Q：顶部显示「模拟模式」，是假的 Redis 吗？ fakeredis 是纯 Python 实现的内存版 Redis，命令、返回值、 行为和真实 Redis 一致，学习完全够用。装好真实 Redis 后重启即切换。
Q：模拟模式的数据重启后去哪了？ 存在进程内存里，重启即清空（学习场景正合适，永远从干净状态开始）。 真实模式的数据按 Redis 自身的持久化配置落盘。
Q：双击后提示没有 Python？ 到 python.org/downloads 安装 3.9+，务必勾选 “Add Python to PATH”，重双击 01。
Q：依赖安装失败？ 在 02-项目源码 内执行：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
Q：端口 5000 打不开？ 看是否已有黑框窗口在运行（避免重复启动）；或等 3 秒 F5 刷新； 仍不行则全关后重双击 01。
