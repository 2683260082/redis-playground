原理 · 这套动作对应的真实代码
def get_or_set(key, ttl, compute):
    value = redis.get(key)          # 1. 先查缓存
    if value is not None:
        return value                # 2. 命中: 直接返回 (~0.1ms)
    value = compute()               # 3. 未命中: 执行慢查询 (800ms)
    redis.set(key, value, ex=ttl)   # 4. 写回 + 设置过期时间
    return value

命中率是缓存系统的核心指标；TTL 防止数据永远不过期， 也让「数据变旧」有明确的时间边界。
